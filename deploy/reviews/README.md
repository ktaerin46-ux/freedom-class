# 수강생 후기 사진 폴더

여기에 카카오톡 후기 캡처 사진을 넣어주세요.

## 파일 이름 규칙

아래 이름 그대로 저장해주세요 (확장자는 .jpg):

- `review-01.jpg`
- `review-02.jpg`
- `review-03.jpg`
- `review-04.jpg`
- `review-05.jpg`
- `review-06.jpg`

## 주의 사항

- 파일을 넣는 즉시 상세페이지에 자동으로 표시됩니다 (새로고침)
- 사진이 없는 자리는 "후기 N" placeholder로 표시됩니다
- 카톡 캡처 비율은 세로형(휴대폰 비율)이 가장 잘 어울립니다
- 배포 시에는 `deploy/reviews/` 폴더에도 같은 사진을 복사해주세요

## 사진 추가/삭제 후

- 6개 미만이면 빈 자리는 placeholder로 보입니다
- 더 많이 추가하고 싶으시면 "후기 자리 더 늘려줘"라고 말씀해주세요
